# AlgoWiz
AlgoWiz is an interactive web-based application designed to demystify complex algorithms by bringing them to life through dynamic visualizations. It serves as an educational tool for students, developers, and anyone interested in understanding the inner workings of computer science concepts. 

## Features

-   **Interactive Visualizations:** Watch algorithms execute step-by-step on a virtual canvas. Each action, such as a comparison or a swap, is clearly highlighted for intuitive learning.
-   **Customizable Inputs:** Define your own data sets (e.g., input arrays) or generate random ones to test algorithms under different conditions.
-   **Comprehensive Algorithm Library:** Explore a wide range of algorithms across various domains, including searching, sorting, and more.
-   **Full Control:** Take charge of the simulation with intuitive playback controls. Play, pause, step forward, or rewind the animation, and adjust the speed to match your learning pace.
-   **Detailed Insights:** Each visualization is accompanied by essential information, such as time and space complexity, to provide a complete understanding of the algorithm's efficiency.
-   **Modern UI:** A clean and responsive user interface, complete with both light and dark modes, ensures a comfortable and focused learning environment.

## Getting Started

Follow these steps to get a local copy of AlgoWiz up and running.

### Prerequisites

-   Node.js 
-   npm

### Installation

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/itzaditya08/algowiz.git](https://github.com/itzaditya08/algowiz.git)
    cd algowiz
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Run the application in development mode:**
    ```bash
    npm start
    ```
    This will start the development server. Open your browser and navigate to `http://localhost:3000` to see the application.

## Technologies Used

-   **React:** The core JavaScript library for building the user interface.
-   **Tailwind CSS:** A utility-first CSS framework for rapid and responsive styling.
-   **Lucide React:** A beautiful and consistent icon library used throughout the application.
